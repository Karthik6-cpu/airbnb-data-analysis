# Airbnb Data Analysis and Price Prediction

## Project Overview

This project analyzes Airbnb listing data to identify pricing patterns, room-type trends, neighbourhood trends, review patterns, and availability.

A machine learning model is also developed to predict Airbnb listing prices using selected features.

## Objectives

- Analyze Airbnb listing data
- Clean and preprocess the dataset
- Identify pricing patterns
- Analyze room types and neighbourhoods
- Study reviews and availability
- Build a machine learning model for price prediction
- Evaluate model performance

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab
- Jupyter Notebook
- GitHub

## Machine Learning

The project uses a Random Forest Regression model to predict Airbnb prices.

### Features Used

- Neighbourhood
- Room Type
- Minimum Nights
- Number of Reviews
- Reviews per Month
- Availability

### Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Results

The analysis identifies important patterns in Airbnb prices, room types, neighbourhoods, reviews, and availability.
